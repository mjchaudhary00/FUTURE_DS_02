## Task 2: Social Media Campaign Performance Tracker

---

### Objective
The objective of Task 2 is to analyze social media marketing campaign performance using engagement and efficiency metrics. The analysis focuses on understanding how different campaigns, channels, locations, and target audiences perform in terms of visibility, engagement, and conversion efficiency.

---

### Dataset
**Marketing Campaign Dataset**

The dataset contains campaign-level performance data including:
- Impressions and Clicks
- Conversion Rate
- Acquisition Cost
- Engagement Score
- Campaign Type, Channel Used, Location, and Target Audience
- Date information for trend analysis

---

### Tools & Technologies
- Microsoft Power BI  
- Power Query  
- DAX  

---

### Data Preparation
The dataset was raw and unstructured. Data preparation involved:
- Renaming and standardizing column names  
- Removing invalid and duplicate records  
- Fixing data types manually to avoid incorrect auto-inference  
- Treating descriptive fields (ROI, Duration, Target Audience) as categorical context  
- Applying business sanity checks before analysis  

---

### Key Metrics Used
- Total Clicks  
- Total Impressions  
- Average Conversion Rate  
- Average Acquisition Cost  
- Average Engagement Score  
- Click Through Rate (CTR)

---

### Analysis Performed
- Evaluated campaign performance using conversion rate and engagement metrics  
- Compared campaign efficiency across channels and target audiences  
- Analyzed geographic reach using impressions by location  
- Studied monthly click trends to identify campaign activity patterns  

---

### Key Insights
- Campaign conversion rates are relatively consistent across campaign types, with minor variations  
- Certain locations contribute significantly higher impressions, indicating stronger visibility  
- Average acquisition cost highlights opportunities for improving cost efficiency  
- Engagement score helps differentiate campaigns with similar conversion performance  

---

### Deliverable
An interactive Power BI dashboard presenting KPIs, campaign comparisons, geographic reach, and time-based trends to support marketing performance evaluation.

---

### How to View the Dashboard
- Download the `.pbix` file from the `Dashboard` folder  
- Open using **Microsoft Power BI Desktop (2021 or later)**  
- Use slicers such as Company to explore campaign-level performance  
- Refer to the `Screenshots` folder for a quick dashboard preview
